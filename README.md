# 🥗 Fitness Advisor

A small, playful, single-file Fitness Advisor web app — practice project for Claude Code skills.

Set your profile (age, height, weight, occupation, sport frequency), log what you eat/drink in plain text, and see your daily calorie budget with simple interactive charts. Everything runs client-side in `index.html` (no build step, no server, no external scripts) with data saved in your browser's local storage.

## Use it

Just open [`index.html`](index.html) in a browser, or enable GitHub Pages on this repo to get a public URL.

## Claude Code skills

This repo also ships two Claude Code skills (see [CLAUDE.md](CLAUDE.md)) for use when chatting with Claude Code here:

- `calorie-estimation` — estimate calories from a food/drink description
- `calorie-recommendation` — recommend a daily calorie target and what to eat for the rest of the day

## Disclaimer

Calorie estimates come from a small built-in keyword list and simple formulas — not verified nutritional or medical advice.
